# TAP Content Atomiser

Take raw source material and produce voice-checked, validated social posts ready for Postiz.

## Account Register (Apply Before Writing Anything)

Different accounts require different registers. Identify the target account before drafting.

### @totalaudiopromo (Instagram brand account — faceless, human)

Faceless but voiced. No "I", no "em", no deliberate typos, no personal-life references, no founder face.

Use observation form: "Most campaigns...", "The thing about cold pitching...", "Before a pitch goes out..."

The brand has opinions and a point of view. It reads like a practitioner speaking to practitioners, without a face attached.

Sentence rhythm: vary it. Mix short punchy lines with longer compound ones. Never write five consecutive sentences of the same length. The staccato style ("Calm. Exact. Precise.") is a brand brief, not a voice — write in actual sentences.

Parenthetical asides are encouraged. (One per post is usually enough.) They give the brand a sense of humour about itself without making jokes.

Hedge when true: "probably", "tends to", "in most cases". Certainty on every sentence is a tell.

### @chrisschouk (Instagram personal / LinkedIn — first-person, casual)

Always first person. Natural imperfections OK on LinkedIn/IG personal: "em" not "them", trailing "..", occasional missing apostrophes in fast words ("arent", "isnt"), casual intensifiers ("makes a ton of difference").

Build-in-public energy: excited but grounded. Personal vulnerability (kids, full-time job, no CS degree).

### LinkedIn (Chris personal)

Same first-person register as @chrisschouk. Hook leads with the insight, not Chris. Link goes in first comment, never the post body. No hashtags. End with a direct question when in build-in-public lane.

## The Pipeline

5 stages, run sequentially. Each stage gates the next.

### Stage 1: Research and Verify

Before writing anything, verify the facts in the source material.

1. Read the source content (vault note, blog draft, raw posts, press coverage)
2. Cross-reference claims against verifiable sources:
   - Releases: check sadact.uk, Spotify, Bandcamp
   - Press: check actual article URLs
   - Product claims: check current TAP state (not old product structure)
   - Stats: only use numbers Chris has confirmed or that are publicly verifiable
3. Flag anything that can't be verified. Don't include unverified claims.

**Key corrections to always apply:**

- TAP is a single app at totalaudiopromo.com (Intel/Pitcher/Tracker are integrated capabilities, not separate products)
- Voice Echo, Playlist Pulse, mini tools ecosystem don't exist
- Gold Soundz: DJ events/booking, 15 years. No workshops.
- Some press interview quotes were AI-generated by Chris. Reference the coverage, not the quotes.
- Chris stopped producing as much after discovering Claude Code. Found coding a creative outlet. Will return to music.

### Stage 2: Voice Gate (BLOCKING — run the script, paste the output)

This is not a skimmable step. Run every post through the voice gate script:

```bash
cd /path/to/total-audio-platform
python3 scripts/liberty-agent/lib/voice-gate.py --all "<post text here>"
```

If the script returns anything other than `PASS — no banned patterns detected.`, rewrite the post and re-run until it passes. Do not include any post in the output without its gate result.

**What the script catches (hard fails):**

- Em dash (unicode `—`) or double-hyphen used as dash
- Banned intensifiers: genuinely, truly, absolutely, definitely, really
- Hard play counts ("12 plays", "50 spins")
- "the kind of X that..." (generic praise structure)
- Banned openers ("Hope you're well", "I hope this email")
- Hype adjectives: stunning, incredible, amazing, fantastic, brilliant
- PR cliches: delighted, pleasure
- **Negation-assertion maxims — BOTH forms:**
  - Period form: "isn't X. It's Y." / "Not X. Y." / "Forget X. This is Y." / "Less X, more Y."
  - Comma form: "isn't research, it's hope" / "won't X, it's Y" / "aren't X, that's Y"
  - The comma form was hardened 29 Jun 2026 — it previously slipped through period-only checks

**Additional voice checks to run manually (not in the script):**

- **Staccato lists**: repeated word at start of 3+ consecutive fragments ("No X. No Y. No Z." / "Just X. Just Y.") — collapse into one sentence
- **Negation runway**: stacking negations to build momentum ("Not a wireframe. Not a suggestion. A page.") — state the positive claim directly
- **Dead AI language**: "delve", "leverage", "landscape", "straightforward", "ecosystem"
- **Dead transitions**: "furthermore", "additionally", "moreover", "moving forward"
- **Engagement bait**: "let that sink in", "read that again", "full stop"
- **AI copywriting tells**: "Enter:", arrow (-->) as structure, "The best part?", "Stopped in my tracks"
- **Rhythm check**: no five consecutive sentences of the same length — mix short punchy lines with longer compound ones
- **British English**: colour, realise, optimise, programme

Check every post individually. Do not batch-approve. If any post fails, rewrite it before moving on.

#### LinkedIn Platform Rules (apply in addition to voice gate)

Read `.claude/docs/linkedin-strategy-logan-gott-apr2026.md` for the full framework. Key rules:

- **Hook leads with value, not Chris** (Gott Rule 4): open with the insight or lesson, not "I built X" or a stat dump
- **Link goes in first comment, never the post body** (Gott Rule 9): include `First comment text:` in the output so it's ready to paste
- **Friday posts** (build-in-public lane): must end with a genuine question, not a CTA
- **Framing**: use "still early, taking on founding users now" not "zero customers" or "still finding my first paying customer" — the latter undermines credibility with PR agency prospects who TAP is built for
- **Personal profile over company page**: all LinkedIn content is from Chris's personal account
- **No hashtags**: Gott framework avoids them; let content carry the reach

### Stage 3: Council Review Gate

Run the batch through the `llm-council` skill before any post reaches the Postiz queue or
human approval. Gate depth depends on post type:

**FULL council** (5 advisors + peer review + chairman) for:

- Brand, founder, campaign, or positioning posts
- Newsletter promo teasers
- Any post that will be used as a flagship piece

Invoke via the `llm-council` skill with:

```
question: "What is weak, dishonest, or generic about these posts? Check: honest tense,
one consistent ask, no AI tells, no redundancy, lead with the distinctive hook."
```

**LIGHT critique** (single Contrarian advisor, 100-150 words) for:

- Routine social variants and repurposed excerpts
- Short update posts

Invoke via a single `Agent` call with the Contrarian role (see
`.claude/docs/llm-council-content-gate.md` for the exact prompt).

Apply all revisions from the council before proceeding to Stage 4. The council catches
judgment-level issues; the voice gate (Stage 2) catches syntactic tells. Both run — the
council feeds rewrites back into the draft.

**Specific checks the council must surface** (carry-forward from prior runs):

- Honest tense: no "now playing" / live status that isn't confirmed true at post time
- One consistent ask: two asks = zero asks
- AI tells: em dashes, double hyphens, tricolons, stacked negations, antithesis clichés
- No redundancy: hook and body should not re-say the same point
- Lead with the distinctive hook: no generic openers

### Stage 4: Visual Render (only if post needs imagery)

If a post in the batch needs a carousel, single image, doc PDF, or chart, render via the `tap-brand-render` skill. Hard rule, no exceptions:

- Never use PIL (`ImageDraw`, `ImageFont.truetype`)
- Never load `/System/Library/Fonts/HelveticaNeue.ttc` or Georgia
- Never use `font-family: -apple-system` in an HTML template

The renderer lives at `scripts/marketing/brand-render/`. Write a JSON manifest, run `python3 render.py manifests/<batch>.json`, eyeball slide-1 against `~/Documents/li-carousels/tap-build-2026-05-13/slide-1.png` (the canonical reference). Module embeds Space Grotesk + Inter woff2 + TAP doodle logo as base64.

Colour palette guidance: see `.claude/skills/tap-brand-render/SKILL.md`. Key rule: vary the `"bg"` field across posts in a batch — no all-cream or all-beige runs. Cyan is a statement colour, use it once per batch maximum.

For diagrams (architecture / flow / sequence, hand-drawn feel), use the `excalidraw` skill instead.

### Stage 5: Output

Write the final posts to `scripts/marketing/social-posts-rewritten.md` (or a dated variant).

Format: numbered list, grouped by theme. For each post include:
- The post text
- `voice-gate.py --all` output (copy-pasted, not paraphrased)
- Account target (@totalaudiopromo / @chrisschouk / LinkedIn)

Include a footer noting how many posts, validation status, and date. If any post has a rendered visual, link to the output dir (e.g. `~/Documents/li-carousels/<batch>/`).

## Voice Quick Reference

These are the key rules. The full reference is `.claude/docs/tap-brand-voice.md`.

- **Tone**: British casual-professional. Calm operator. Not a startup founder performing energy.
- **Physical verbs**: "sanded down" not "improved", "bolted on" not "added"
- **Parenthetical asides**: encouraged for editorial commentary and deflating seriousness
- **Contractions always**: don't, can't, won't
- **Hedge naturally**: "I think", "probably", "kinda", "reckon"
- **No hashtags on X**: let the content speak
- **Shorter is better**: if the Overloaded Plugger would scroll past it, cut it
- **Product mentions incidental**: TAP should feel like a natural aside, not the point
- **Varied rhythm**: mix short punchy lines with longer compound ones — no staccato runs
